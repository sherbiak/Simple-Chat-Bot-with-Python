# Simple Chat Bot

A simple interactive Python console bot that greets you, guesses your age using a mathematical trick, counts to any chosen number, and tests your programming knowledge.

## Prerequisites

* Python 3.8 or higher installed on your system.
> **Note:** The included virtual environment configuration targets macOS and Linux. If you want to run this project on Windows, you must create a new local virtual environment first.

## Setup & Running

### 1. Activate the Virtual Environment

Before running the script, activate the project's virtual environment:

* **macOS / Linux:**
```bash
source .venv/bin/activate
```

### 2. Run the Bot

Execute the script using:

```bash
python bot.py
```

### 3. Deactivate the Environment

When you are done, exit the virtual environment by running:

```bash
deactivate
```
